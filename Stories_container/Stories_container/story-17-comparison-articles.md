# Story 17: Create Comparison Articles

**Epic:** Content Strategy
**Priority:** P2 — Medium
**Effort:** Medium
**Type:** Content Creation

---

## Description

As a potential customer comparing engineering automation options,
I should find comparison content on Inventive's website,
so that I can understand how Inventive differs from traditional methods and competing approaches.

---

## Current State

No comparison content exists anywhere on the website. The "Traditional vs Smart PID Workflow" table from the Smart PID PRD is not on the website.

---

## Comparison Pages to Create

| # | Page Title | Comparison |
|---|-----------|------------|
| 1 | Traditional P&ID vs Smart PID | Manual Plant 3D drafting vs wizard-based automation |
| 2 | Manual Support Extraction vs AI Extraction | Screenshot + manual drafting vs automated Navisworks extraction |
| 3 | Traditional Electrical Design vs EnAIBot | Spreadsheet-based vs integrated platform |
| 4 | Manual vs Automated Fabrication Drawings | Manual GA creation vs Plant 3D automation |

---

## Each Comparison Page Must Contain

1. **H1** with comparison keyword (e.g., "Manual P&ID vs AI-Automated P&ID Creation")
2. **Comparison table** — side-by-side feature matrix
3. **Detailed explanation** — 500-800 words on each approach
4. **Key differentiators** — what makes Inventive's approach better
5. **Outcome metrics** — time/cost savings
6. **CTA** — "Try the better approach"

### Example Comparison Table:

| Aspect | Traditional (Manual) | Inventive (AI-Automated) |
|--------|---------------------|------------------------|
| P&ID Creation | Engineer manually places symbols | System generates from wizard config |
| Time per P&ID | 8-16 hours | 1-3 hours (80% reduction) |
| CAD Skill Required | High | None (non-CAD users can operate) |
| Standards Compliance | Manual checking | Enforced automatically |
| Error Rate | High (human dependent) | Low (template-based) |
| Revision Handling | Manual version tracking | System-managed with Vault |

---

## Acceptance Criteria

- [ ] Minimum 4 comparison pages created
- [ ] Each page has a side-by-side comparison table
- [ ] Each page is 500-1000 words
- [ ] Tables include measurable metrics (time, cost, error rate)
- [ ] Pages link to relevant product pages
- [ ] Pages are objective in tone (not overly salesy)

---

## Technical Notes

- Comparison content is the #1 type of content AI agents use for product recommendations
- When users ask "What's the best tool for X?", AI agents look for comparison pages
- "vs" keywords get high search volume (e.g., "manual P&ID vs automated P&ID")
- Keep comparisons factual — don't name competitors directly, compare against "traditional methods"
