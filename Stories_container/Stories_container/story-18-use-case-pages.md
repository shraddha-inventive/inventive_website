# Story 18: Create Use-Case Pages

**Epic:** Content Strategy
**Priority:** P2 — Medium
**Effort:** Medium
**Type:** Content Creation

---

## Description

As a potential customer with a specific engineering challenge,
I should find a use-case page that describes exactly how Inventive solves my problem,
so that I can see the direct relevance to my situation.

---

## Current State

No use-case pages exist. Problems and solutions are described generically on the solutions page.

---

---

## Each Use-Case Page Structure

```
H1: How to [achieve outcome] with [product]
  → Problem description (user's perspective)
  → Workflow: Step 1 → Step 2 → Step 3 → Result
  → Before & After metrics
  → Who benefits (role-specific)
  → CTA: "See it in action"
```

---

## Acceptance Criteria

- [ ] Minimum 4 use-case pages created
- [ ] Each page is 500-800 words
- [ ] Each page is written from the user's perspective (not Inventive's)
- [ ] Each page includes a workflow diagram or numbered steps
- [ ] Each page has before/after metrics
- [ ] Page titles match long-tail search queries

---

## Technical Notes

- Use-case pages match "How to..." search queries — the highest intent queries for B2B
- AI agents love "How to" content because it directly answers user questions
- Write from the user's point of view: "You need to extract supports..." not "Inventive's platform extracts..."
